Reporting API

Connecticut Nursing Home Reporting API

Public CMS, CT DSS and CT DPH records about Connecticut nursing homes as plain JSON files, built for people, scripts and AI assistants. Every finding says where it came from.

OpenAPI specllms.txtllms-full.txtCatalogReport builder

Screening information only. This data is public records, not findings of violations. It contains no resident data and no Ombudsman case data.
Overview

How it works

danbeem.xyz is hosted on GitHub Pages, so the API is a set of precomputed static files under /api/v1/. That has a few consequences:

  • Every URL ends in .json and parameters are part of the path. There is no ?q= query.
  • Facilities are identified by CCN, the 6-character CMS Certification Number (for example 075396).
  • An unknown id returns the host's HTML 404 page, not JSON.
  • No login, no rate limits, CORS open. Files are rebuilt when site data is refreshed; check generated_at and data_as_of.
  • Missing data is null plus an entry in missing_data[].
Quick start

Try it with curl

# Catalog: URL templates, sources, as-of dates
curl -s https://danbeem.xyz/api/v1/index.json

# One facility (Cherry Brook Health Care Center)
curl -s https://danbeem.xyz/api/v1/facilities/075396/profile.json

# Evidence-labelled report
curl -s https://danbeem.xyz/api/v1/reports/related-party-screening/075396.json

# Findings only, as text (needs jq)
curl -s https://danbeem.xyz/api/v1/reports/facility-comprehensive/075396.json \
  | jq -r '.findings[] | "[" + .kind + "] " + .statement'

Reports

Report types

Facility reports live at /api/v1/reports/{report_type}/{ccn}.json. All share one envelope: subject, executive_summary, findings, metrics, historical_trends, relationships, sources, limitations, missing_data, recommended_follow_up, links. Schema: report.schema.json.

report_typeUse it for
facility-comprehensiveDefault. Everything about one home.
ownership-networkWho CMS lists as owner/controller, managers, administrators; shared principals.
staffing-analysisNursing hours per resident day by quarter vs CT minimum and state median.
financial-transparencyDSS cost-report spending, direct care, management fees, related parties.
regulatory-historyHealth citations, immediate jeopardy, fines, payment denials.
related-party-screeningRelated parties and management fees on cost reports, shared principals, names asked about but absent.
management-company-portfolioTakes a company id. Homes the company is listed at, with periods.

To compare two homes, fetch two facility-comprehensive reports and compare them in your client. There is no comparison file.

Evidence model

Evidence kinds

kindMeaning
confirmed_factValue printed in a public source record.
calculatedArithmetic on confirmed facts; the formula is given.
possible_associationShared entity, name or principal. Not evidence of ownership, control or conflict of interest.
investigative_questionSomething the data cannot answer that a person should check.

Each finding has evidence[] with agency, dataset, url, reporting_period, as_of, record_id and verification (source_record, source_record_unvalidated, derived or name_match_unverified).

A possible association is never evidence of ownership, control or a conflict of interest. "No record found" means "not in these datasets", never "no problem".
Finding a home

Search

Static hosting has no server-side search. Download search-index.json once, normalize your query the same way as each entry's key (upper case, punctuation and suffixes such as INC or LLC removed) and match substrings. Entries have type, id, name, ccns and key. Names are never merged; the same name under two ids stays two entries. A name that is not in the index is not in any dataset on this site.

curl -s https://danbeem.xyz/api/v1/search-index.json \
  | jq -r '.entries[] | select(.key | contains("CHERRY BROOK")) | [.type, .id, .name] | @tsv'
AI assistants

Using it with ChatGPT, Claude and Hermes

  • ChatGPT and Claude: turn on web access so the assistant can fetch public URLs, then give it a report URL and ask your question. The Reports page has preset questions and prompts. Point assistants to llms.txt for the rules.
  • Hermes (self-hosted): use the standard-library client scripts/reporting_api_client.py.
python3 scripts/reporting_api_client.py search "cherry brook"
python3 scripts/reporting_api_client.py profile 075396
python3 scripts/reporting_api_client.py summary related-party-screening 075396
python3 scripts/reporting_api_client.py company mc-apple-health-care-inc
# Test against a local checkout without the network:
python3 scripts/reporting_api_client.py --local api summary facility-comprehensive 075396

When summarizing, assistants should cite agency, dataset, reporting period and record id for each claim, keep the four evidence kinds separate, and never call a possible association a conflict.

Limits

Limitations

  • Public CMS, CT DSS and CT DPH data only. No resident data. No Ombudsman case data.
  • Snapshots: each source has its own as-of date in index.json.
  • Payroll data shows hours paid per day, not shifts or care given. Comparisons with Connecticut minimums are estimates.
  • Cost-report text read from PDFs may be truncated; check validated_against_printed_totals.
  • Entities are matched only by CCN, CMS associate id, DPH license number or management company id. Name matches are labelled name_match_unverified.
  • Absence from these datasets does not mean absence in the world.
